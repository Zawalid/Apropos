# Cue

A native macOS command center that knows what you are doing.

One hotkey opens a fast, fluid panel. It reads the frontmost app, the selection, and the current document or URL,
and shows the actions that matter for that moment. Do something once in any app and it becomes a command.

Cue is a working name and may change.

Status: planning. See [docs/design.md](docs/design.md) for the full idea and [docs/roadmap.md](docs/roadmap.md)
for the build order.
