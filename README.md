# Apropos

A native macOS command center that knows what you are doing.

One hotkey opens a fast, fluid panel. It reads the frontmost app, the selection, and the current document or URL,
and shows the actions that matter for that moment. Do something once in any app and it becomes a command.

Formerly Cue. Renamed to Apropos ("fitting the moment") before the first release; your settings, usage and symbol
packs from the Cue folder are carried over once on first launch. See [docs/rename-to-apropos.md](docs/rename-to-apropos.md).

Status: M0 (foundation) is built: global shortcut, floating palette, the frontmost app's menu commands with fuzzy
search, and Accessibility onboarding. See [docs/design.md](docs/design.md) for the full idea,
[docs/roadmap.md](docs/roadmap.md) for the build order and [docs/development.md](docs/development.md) to run it.
