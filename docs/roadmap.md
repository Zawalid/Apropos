# Roadmap

Each milestone is one `/goal` run. Finish and verify one before starting the next.

## M0: Foundation
Project scaffold, dev loop, global hotkey, floating panel, frontmost-app tracking, accessibility menu reading,
fuzzy search, run a menu item, permission onboarding, tests, CI.

## M1: Context and ranking
Selection, file, URL and document-title sensing. Per-app pinned and most-used actions. Learned ranking stored locally.

## M2: Record-to-command
Capture accessibility-element sequences, name and bind them, replay reliably, survive small UI changes.

## M3: Command library
User command editor, Shortcuts, App Intents and AppleScript backends, starter packs for a few apps.

## M4: Polish and ship
Design pass, onboarding, Sparkle updates, notarized release, website, license and billing.

## v2
Cross-app actions, maintained pro-tool packs, sync and team packs (Pro).
